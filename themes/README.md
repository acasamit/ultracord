# Themes

Phoenix draws its UI natively, without CSS, so a theme means remapping Discord's color tokens
inside Sunbird. That support is being worked on upstream
([sunbird-tools/sunbird#10](https://github.com/sunbird-tools/sunbird/pull/10)).

Theme submissions open once it lands. Themes will be JSON files, with screenshots, and fonts or
icons hosted here rather than on third-party sites.
